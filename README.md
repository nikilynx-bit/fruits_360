# Fruits 360 Image Classification Project

## 📌 Project Overview
This project aims to build an automated system capable of identifying and classifying various types of fruits, vegetables, nuts, and seeds from images. This can be applied to automated grocery sorting, dietary tracking applications, or inventory management in the agricultural sector.

## 📂 Dataset Information
* **Source:** [Kaggle - Fruits-360 by moltean](https://www.kaggle.com/datasets/moltean/fruits)
* **Size:** Over 90,000+ images.
* **Classes:** 131+ categories of fruits and vegetables [[8]].
* **Image Resolution:** 100x100 pixels [[3]].
* **Background:** Primarily solid white background (due to the 360-degree rotation recording method).

## 🛠️ Approaches
This repository documents two distinct methodologies for achieving the project goal:
1. **[No-Code Approach](./NO_CODE_APPROACH.md):** Leveraging AutoML platforms and GUI-based tools for rapid prototyping and deployment.
2. **[Code-Based Approach](./CODE_APPROACH.md):** A full Python lifecycle using PyTorch/TensorFlow, covering scoping, cleaning, EDA, modeling, and evaluation.

## 🚀 Getting Started
1. Download the dataset from Kaggle using the Kaggle API or manual download.
2. Extract the contents into a `data/` directory.
3. Follow the steps in either the No-Code or Code-Based approach documents.
